# Bug reports and feature requests

**Use [GitHub Issues](https://github.com/mbsintegrations/HomeAssistant-Sigenergy-TC/issues) only for bug reports and feature requests.** Reports sent by email, Facebook comments, Messenger, private messages or other channels are not tracked as support requests. Please open an issue even if you first noticed the problem in a discussion elsewhere.

Search existing issues first, then choose **Bug report** or **Feature request**. For a bug, include the integration and HA versions, connection choices, relevant plant model/firmware, steps to reproduce, expected/actual behavior and a sanitized screenshot or diagnostic excerpt when useful. A feature request should describe the desired result and why it helps.

Never attach passwords, tokens, device serials, plant addresses or unredacted Cloud responses/recovery journals. Review screenshots and diagnostics before uploading. Do not use a public bug report to disclose a security vulnerability; follow [SECURITY.md](SECURITY.md).

Sigenergy TC is in public Beta. See [installation](docs/installation.md), [dashboard/drop-in placement](docs/dashboard-embedding.md#choose-where-to-put-it) and [release notes](https://github.com/mbsintegrations/HomeAssistant-Sigenergy-TC/releases/tag/0.2.10) before reporting a setup problem.
